Goods Management & Billing System (C++)

##  Features
- User authentication
- Product management (Add, Update, Delete, Search)
- Billing system with invoice generation
- File-based data storage

## Technologies Used
- C++
- File Handling (Binary Files)

## How to Run
g++ main.cpp product.cpp auth.cpp billing.cpp -o output
./output

## LIMITATIONS
- Console-based UI
- Limited product capacity (10 per bill)
